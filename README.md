## Quick description of the game

This is (supposed) to be a cyberpunk-style roblox game where you're basically a Ripperdoc in Night City, which means you install illegal and back-alley cyberware on people in a fictional city. It will include a customisable space, along with minigames to install the cyberware.

This game takes inspiration from games like Cyberpunk 2077, my restaurant, the Edgerunners series, along with the cyberpunk genre in general for the aesthetic of the game.

## Current features
- 1 minigame to install cyberware (more to be added soon, also the UI needs to be fixed)
- placing down blocks on the map (sort of complete still needs a lot of work)
- UI for placing down the blocks
